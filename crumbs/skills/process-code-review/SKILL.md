# Process code review

Read the review comments on the pull request and decide whether you agree with each one. Reply to each comment, explaining your decision. Implement the changes you agree with and run the relevant tests. Push the tested changes to the PR, then mark the addressed review threads as resolved. If you disagree with a comment, explain why and leave it unresolved.
