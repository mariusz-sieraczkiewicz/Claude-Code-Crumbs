# In My Shoes

Concisely present the skill argument: {{args}}

Be empathetic that the user did not take part in the creation process and does not know the details — they only function at the level of information they themselves wrote during this session. If no argument is given, concisely present the most important outcome of the current work.

## How to apply this

- Write in plain language, without technical jargon (and if you must use it, explain it immediately).
- Do not refer to things the user has not seen directly (e.g. internal file names, steps, or identifiers) — if you must mention them, briefly describe what they are.
- Focus on concrete facts: what was done, what it means, and what was skipped or requires a decision from the user.
- Keep it concise — as much as needed, no more.
