# Format: x-post

**Goal:** stop the scroll and drive to the blog post. Provide both a single post and a thread. → `x-post.md`

## 1. Single post (≤280 chars)

- Lead with the sharpest line — the result, the surprise, or the contrarian take. No "I wrote a blog about…".
- One idea. End with the link.
- Plain language; at most 1–2 hashtags inline if natural.

## 2. Thread (3–7 tweets)

- **T1** = the hook, strong enough to stand alone; no link yet (links suppress reach in the first tweet — put it in the last).
- **T2…Tn-1** = one beat each, mirroring the blog's points. Concrete: a number, a snippet, a before/after.
- **Tn** = takeaway + the blog link + CTA.
- Number them `1/`, `2/`… Each tweet ≤280 chars and readable on its own.

## Tags (target the blog entry)

Pick **2–4 hashtags that match the blog's `tags`** so the post and article target the same audience/search. Add @handles only when genuinely relevant (a tool's account, a person quoted). List them explicitly at the bottom under `Tags:` so they can be tuned without touching the copy.

## Voice

No threadboi clichés ("Let that sink in", "🧵👇" as the whole tweet, "A thread:"). Earn attention with substance. No emoji bullets.

## Skeleton

```
SINGLE:
{hook line} {link} {#tag #tag}

THREAD:
1/ {hook}
2/ {point + concrete detail}
...
n/ {takeaway} {link}

Tags: #... #... (matched to blog tags)
```
