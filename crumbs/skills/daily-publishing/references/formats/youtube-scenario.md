# Format: youtube-scenario

**Goal:** a shooting plan that turns the subject into a tight ≤10-minute video. This is the *script/structure*, not the slides. → `youtube-scenario.md`

## Shape

1. **Logline** — one sentence: who it's for + what they'll be able to do after.
2. **Title + thumbnail idea** — the curiosity-or-payoff title; one line on the thumbnail visual/text.
3. **Beat sheet** with rough timestamps summing to ≤10 min:

| Beat | Time | On screen | The point to land |
|------|------|-----------|-------------------|
| Hook | 0:00–0:15 | … | why watch — the payoff or stakes, fast |
| Setup | … | … | the problem / context |
| Beat 1–4 | … | … | one idea each, in order |
| Payoff | … | … | the result / it working |
| Outro/CTA | last 15s | … | subscribe + link |

## Writing rules

- **Hook in the first 15 seconds** — state the payoff before any intro; no long channel intro.
- Per beat: what's *shown* (talking head, screen recording, diagram) + the line to land. Mark capture notes in *italics* (e.g. *screen-record the failing test*).
- Write spoken cadence — short sentences, contractions, signposting ("first", "the catch is", "so here's the fix").
- Keep one idea per beat; if a beat needs two, split it.

## Skeleton

```markdown
# {video title}
Logline: ...
Thumbnail: ...

## Beats
- 0:00 Hook — *on screen:* ... | say: ...
- 0:15 Setup — ...
- ...
- 9:30 Outro — subscribe + link
```
